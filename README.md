##  Overview

**EasyPay** is a high-fidelity fintech dashboard engineered for the modern era. Merging the power of **React 18** with the aesthetic brilliance of **Tailwind CSS**, it delivers a seamless, native-app-like experience right in your browser.

Featuring a trend-setting **Glassmorphism** design system, beautiful data visualization, and an intelligent **AI Financial Assistant**, EasyPay redefines how users store, spend, and save their money.

---

##  Features at a Glance

###  **Stunning UI/UX**
- <img src="https://img.icons8.com/color/20/000000/monitor.png"/> **Glassmorphism Design**: Premium frosted glass effects, vivid gradients, and deep shadows.
- <img src="https://img.icons8.com/color/20/000000/smartphone--v1.png"/> **Fully Responsive**: Optimized for every screen, from 4K desktops to mobile devices.
- <img src="https://img.icons8.com/color/20/000000/animation.png"/> **Smooth Animations**: Custom `fadeIn`, `slideUp`, and micro-interactions.

###  **Smart Intelligence**
- <img src="https://img.icons8.com/color/20/000000/bot.png"/> **Ask AI Chat**: Built-in AI to analyze spending habits and offer credit score advice.
- <img src="https://img.icons8.com/color/20/000000/flow-chart.png"/> **Dynamic Routing**: Zero-latency navigation between modules.

###  **Powerful Financial Tools**
- <img src="https://img.icons8.com/color/20/000000/money-box.png"/> **My Savings (Emergency Mode)**:
  -  **Auto-Save**: Set daily deductions (e.g., ?5/day) automatically.
  -  **Instant Withdraw**: One-tap transfer back to your primary bank.
- <img src="https://img.icons8.com/color/20/000000/bell--v1.png"/> **Smart Notification Center**:
  -  **Pinned Alerts**: Critical warnings stay on top.
  -  **Date Grouping**: Smartly organizes history by "Today", "Yesterday".
  -  **Activity Graph**: Visual volume of your alerts.

##  Installation & Setup

Get running in less than 2 minutes.

```bash
# 1. Clone the repository
git clone https://github.com/Rahulchaube1/EasyPay.git

# 2. Navigate to directory
cd EasyPay

# 3. Install dependencies
npm install

# 4. Fire up the engine 
npm run dev
```

##  Mobile Preview
Experience the app on your phone (Local Network):
1. Run `npm run dev -- --host`
2. Look for the **Network URL** in the terminal (e.g., `http://192.168.1.5:5178`)
3. Open it on your mobile browser.
