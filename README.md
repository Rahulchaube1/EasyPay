##  Overview

**EasyPay** is a high-performance, visually stunning fintech dashboard engineered for the modern web. It combines **React's** component architecture with **Tailwind's** utility-first styling to deliver a native-app-like experience in the browser.

Featuring a fully responsive **Glassmorphism** design system, interactive charts, and an integrated **AI Assistant**, EasyPay sets a new standard for personal finance tools.

##  Key Features

###  **Immersive UI/UX**
- **Glassmorphism Design**: Frosted glass effects, vibrant gradients, and smooth transitions.
- **Responsive Layout**: Flawless experience across Mobile, Tablet, and Desktop.
- **Smooth Animations**: Custom `fadeIn` and slide effects for a polished feel.

###  **Smart Technology**
- **AI Finance Chat**: Integrated chatbot for credit analysis and spending advice.
- **Dynamic Routing**: Instant navigation without page reloads.

###  **Financial Tools**
- **My Savings (Emergency Fund)**: 
  - Daily auto-save logic (default ?5/day).
  - Instant withdrawal to linked bank account.
  - Visual savings tracker.
- **Advanced Notification Center**:
  - Pinned critical alerts (Low Balance).
  - Date-based grouping (Today, Yesterday).
  - Activity visualization graphs.

##  Getting Started

Clone the repository and run the development server locally:

```bash
# 1. Clone the repository
git clone https://github.com/Rahulchaube1/EasyPay.git

# 2. Navigate to project directory
cd EasyPay

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

##  Mobile Preview
To view on mobile within the same network:
1. Run `npm run dev -- --host`
2. Open the Network URL (e.g., `http://192.168.x.x:5178`) on your phone.
